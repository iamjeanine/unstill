# unstill

A narrative experience that reconstructs the worlds around 1920s police mugshots from the Museums of History NSW archive. Colorized portraits, AI-generated animation, researched essays, and live contextual inscriptions that change on every visit.

[unstill.vercel.app](https://unstill.vercel.app) · **Desktop only, best with sound**

## What it does

Seven stories from the Sydney Police Special Photographs Collection. Each one pairs a colorized, animated portrait with a narrative essay grounded in court records, press clippings, and the photographs themselves. A canvas-based loupe lets you hover over the animation to reveal the original glass plate negative underneath. Contextual inscriptions generate live through the Anthropic API, surfacing historical details about the world around each person. No two visits are the same.

## Stack

React · Vite · GSAP ScrollTrigger · Canvas API · Anthropic Claude API · Vercel serverless proxy · Google Veo 3.1 (AI animation) · AI colorization
